# `@deepseek-ai/dsh-client-ui-graph`

[English](README.md) | 中文

## 概述

使用浏览器 Graph 面板检查不可变设计、执行证据、修订和 Campaign 批次，并管理会话及全局角色设置。Host 始终是图状态的权威来源，并验证每项持久化操作。

## 使用此软件包

需要在会话中检查运行、修改设置或执行受支持的节点操作时，请使用 Graph 客户端。

<a id="understand-the-implementation"></a>
## 了解实现

客户端渲染 Host 投影，并发送带有修订、代次和尝试标识的命令；客户端不拥有权威 Graph 状态。

Graph 工作区包含设计、实现和修订三个一级页签。修订页把逻辑任务显示为纵向泳道，并让其不可变修订从左向右推进。带类型的曲线会区分计划重构、执行修正、历史父关系和跨 Batch 依赖。搜索覆盖任务文本、角色、实际模型路由与错误码；类型和 Run 状态筛选以及有界展开让长历史保持可导航。延迟悬停预览会显示目标与触发原因，选择后固定抽屉会显示创建原因、任务图差异、运行指标、关系、安全事件引用，并可直接进入所选设计或实现视图。没有 lineage 的历史提交会明确显示为未分类，缺失的子会话遥测不会伪装成零。

浏览器端在会话标题栏注册一个入口，而且只在该会话的 `graph` 投影处于激活状态时显示。设计页只显示主控编写的不可变任务图。实现页左侧显示所选运行的任务图，右侧显示可滚动的节点摘要列表；选择任务图节点或摘要会打开完整证据与操作弹窗。DOM 控件和全部 Cytoscape 画布共用一套跨平台阅读字体，并把字重约束为清晰的 400/500 两档；结构化 JSON、检查点和标识符则使用禁用连字的 Cascadia Mono／Consolas 风格字体栈。当前只读有向画布由 Cytoscape 渲染，使用平滑依赖曲线和中等字重的节点标签，并提供显式适应视图与缩放控制、方向键节点导航和用于大型任务图的概览。运行证据或节点选择变化时，当前画布会保留视口；只有所选不可变 Revision 发生变化或用户请求适应视图时，画布才会重新布局并适应视图。节点弹窗展示强制执行的输出 Schema、条件成员与分支决定、扩展或子图定义、执行来源、检查点、每个节点的耗时、实际角色/模型/Worker 路由、执行尝试、输出、产物、操作日志、Settlement、终止规则、LoopX Claim ID 和子会话入口。标题栏会显示最新一次尝试的权威完整子会话入口，让完整消息和工具事件可被立即访问；续跑子会话入口仍归属于各自的执行尝试。

投影包含 Campaign 时，面板会在画布上方显示有序的横向 Batch 轨道。标题展示持久计划修订号；每张卡片展示引入它的计划修订、目标、持久状态、最新 Revision 和 Settlement 数量，提示框还会展示扩展原因以及来源 Batch、Run 与 Settlement 数量。选择已完成卡片会打开该 Batch 的独立历史 Graph；它不会把 Batch 节点合并到当前 Graph，也不会改变持久化的当前 Graph 身份。主控尚未创建 Graph 的 Planned Batch 保持不可点击。

活动运行控制条只在适用阶段提供暂停与终止，并针对 `awaiting_user` 外部结果提供对账；检查点提供结构化批准与拒绝，但任务修改检查点不会显示批准操作，因为只有其替代 Revision 可以完成解析。节点控制项根据所选节点状态提供书面任务修改请求、终止、重试、恢复、跳过、分派覆盖和通过 Schema 校验的替代输出。任务修改会成为持久检查点并交回主控生成新的不可变 Revision，而不是编辑执行历史。每个浏览器请求都携带投影中的任务图修订、运行 Generation 与最新 Attempt 身份，因此过期标签页不能影响更新后的工作。面板等待 Host 命令结果，并展示持久操作时间线中的操作者、来源、预期与结果 Generation、结果和完成时间。

Graph 尝试创建的主子会话与续跑子会话会获得紧凑的 Graph 节点入口。该入口会根据父会话投影识别当前子会话，展示实际角色、模型、推理强度选择器、节点阶段和尝试号，提供返回父任务图的导航，并通过父会话命令通道携带准确的修订、Generation 和 Attempt 身份终止运行中的节点。普通子代理会话不会显示 Graph 入口。

标题栏设置操作会打开编辑器，并通过 `/graph config <JSON>` 修改持久化 Graph Mode 配置。每个角色从由设置功能维护的共享模型目录中选择提供方／模型组合，也可继承会话路由；推理强度保留为自由文本，因为不同提供方接受的取值不同。编辑器还提供活动子代理总数上限、全局 worker 上限、主控预留、角色上限、提示词、精确模型上限、有序主控兜底路由、适用失败码、每轮兜底上限，以及 Graph 专用的压缩阈值、保留比例、输出 token 与推理强度设置。每个兜底路由都可以独立用于主控恢复、会话压缩或两者。可见的页脚让保存操作始终位于可滚动角色列表之外。编辑器打开期间，无关的运行投影不能替换当前编辑草稿。Host 在追加事件前校验整个替换值；命令拒绝会保留草稿并显示错误，浏览器不保存权威任务图状态。

插件设置页还会注册一个独立于活动会话的 Graph 角色模板页。它读取不绑定会话的模型目录，并提供与会话编辑器相同的并发、主控兜底与压缩设置；随后校验完整模板，拒绝超过 Node Timer 上限 `2_147_483_647` 的毫秒策略值，并通过带修订号保护的 `graph-mode` 设置命名空间保存。发生并发编辑时，本地草稿会保留，并要求用户显式重新载入。会话只在首次启用 Graph 时复制模板，因此后续全局编辑不会改变既有会话的角色提示词、模型路由、限额、压缩、回放或恢复结果。

## 开发备注
UI 不发布不变量 companion：Graph 状态由 Host 投影，客户端测试覆盖 slot 释放。


<a id="model-experience"></a>
## 模型体验

### 任务图面板与设置

#### 模型看到的内容

浏览器插件不会贡献提示词或工具文本。只有在 Host 校验并记录 `/graph config <JSON>` 替换值之后，设置才会影响后续请求。

#### Token 影响

面板本身不会增加 token；配置后的角色提示词和模型选择由 `dsh-graph-mode` 渲染。

#### KV Cache 影响

浏览器不会添加缓存内容。修改角色提示词后，该角色先前可复用的提示词前缀对后续子代理请求失效。

## 已知限制与待完成工作 <a id="known-limitations-and-deferred-work"></a>

- 设计和实现页签只在激活期间分别挂载各自的 Cytoscape 实例。它们的拓扑和适应视图行为一致，但切换页签后不会保留平移与缩放状态。
- 会话编辑器与插件设置中的 Graph 模板编辑器均支持角色新增、复制、排序、编辑、启用、停用、删除、模型路由、推理强度与并行限制。全局编辑器只会在用户明确进行第二次确认后恢复内置软件工程团队。
- 模型限流编辑会生成精确的提供方/模型限额。JSON 配置仍支持加权内存限额，但面板尚未展示该字段。
